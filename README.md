# Polymarket Bot – Kalshi 15‑minute Desk

## Overview
This repository contains the Kalshi 15‑minute BTC trading bot (Desk 3). The bot discovers the active 15‑minute market, evaluates delta vs. deadband, and places live orders when conditions are met.

## Recent Fix (2026‑09‑29)
- **Market discovery** now queries `status="open"` first, ensuring the newly‑opened contract is captured immediately.
- A fallback query (`status="active"`) remains for edge cases.
- The function `get_btc_15m_markets()` now sorts results by close time and excludes expired contracts.

## Running a Sanity Test
```powershell
python -u -c "from kalshi_trader_15m import KalshiTrader15M; bot = KalshiTrader15M(); bot.run_cycle()"
```
The output will show the active market, spot, strike, delta and deadband. If delta lies within the deadband, the bot will *preserve capital* (no trade). To force an entry for testing, temporarily lower `DEADBAND_BPS` or `DEADBAND_MIN_FLOOR` in `kalshi_trader_15m.py` and revert after verification.

## Dashboard
The dashboard (`dashboard_server.py`) reads the same journal (`kalshi_trading_journal.json`) and updates the `kalshi_radar` card with real‑time spot, strike, delta, deadband and status signals.
